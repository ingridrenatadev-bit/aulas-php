

# 🚀 Meu Aprendizado em PHP: Fundamentos

Bem-vindo ao meu repositório de estudos! Este espaço foi criado para registrar a minha evolução, exercícios e anotações sobre os conceitos fundamentais do PHP. 

---

## 📌 Conteúdos Estudados

### 📂 Sintaxe Básica e Configuração
- Abertura e fechamento de tags PHP (`<?php ?>`)
- Comando de saída de dados (`echo` e `print`)
- Comentários de linha única (`//`, `#`) e de múltiplas linhas (`/* */`)

### 🧮 Variáveis e Tipos de Dados
- Criação e regras de nomenclatura de variáveis (`$nome Variavel`)
- Tipos de dados primitivos:
  - Strings (Textos)
  - Integers (Números inteiros)
  - Floats / Doubles (Números decimais)
  - Booleans (`true` ou `false`)
- Concatenação e interpolação de strings

### 🧠 Estruturas de Controle (Condicionais)
- Tomada de decisão com `if`, `else` e `elseif`
- Operadores de comparação (`==`, `===`, `!=`, `<`, `>`, etc.)
- Operadores lógicos (`&&`, `||`, `!`)
- Estrutura de escolha múltipla `switch`

### 🔄 Estruturas de Repetição (Loops)
- Laços de repetição tradicionais: `while` e `for`
- Execução garantida com `do-while`
- Iteração de arrays com `foreach`

### 📦 Arrays e Funções Básicas
- Criação de arrays simples (indexados) e arrays associativos (chave => valor)
- Criação de funções personalizadas (com e sem parâmetros/retornos)
- Manipulação básica de strings e números com funções nativas do PHP
